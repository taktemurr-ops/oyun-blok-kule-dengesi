# Denge Kulesi

Bilgisayara karşı sırayla kuleden blok çekip tepeye koyun. Bir kat ortası ya da iki yanı varsa ayakta kalır; güvenli hamlesi kalmayan kaybeder. Konumlar tam çözülür: her bölüm oyuncunun kazanabileceği şekilde kurulur, ipucu kazandıran hamleyi gösterir. Blok Oyunları merkez uygulamasının oyunu.
